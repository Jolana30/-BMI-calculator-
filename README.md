## ✨ Features

- 🎨 **Clean, modern UI** — Light blue/cyan theme with smooth animations
- 👤 **Gender selection** with illustrated characters (male & female SVG illustrations)
- 📏 **Interactive sliders** for height, weight, and age
- 🔄 **Unit toggle** — Switch between Metric (kg/cm) and Imperial (lbs/in)
- 📊 **Circular BMI gauge** with color-coded segments (underweight → obese)
- 💡 **Health insights** — Personalized feedback based on your BMI category
- 📈 **Additional stats** — Ideal weight range, BMR, TDEE, daily water intake
- 📱 **Mobile-first design** — Responsive, app-like experience
- 🎭 **Smooth transitions** between input and results screens

## 🎨 Design Inspiration

Inspired by [BMI Calculator Mobile App UI Kit (Pinterest)](https://pin.it/1XHhQe4pi)

## 🚀 Tech Stack

- **HTML5** — Semantic markup
- **CSS3** — Custom properties, gradients, animations, responsive design
- **Vanilla JavaScript** — No frameworks or dependencies
- **SVG** — Hand-crafted character illustrations and gauge

## 🛠️ Getting Started

Simply open `index.html` in your browser — no build step or dependencies needed!

```bash
# Clone the repo
git clone https://github.com/Jolana30/bmi-calculator.git

# Open in browser
open index.html
```
